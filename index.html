About me

I'm a Full Stack Developer with a strong focus on the frontend: responsive, client-facing web applications that load quickly and are easy to use.

I recently completed the Codecademy Professional Certification in Back-End Engineering, which covered REST APIs, SQL/PostgreSQL, web security and application infrastructure and scalability.

I've delivered real client work, including a study-abroad publishing platform and an e-commerce site with cart and admin functionality. I'm currently pursuing a BS in Information Technology and looking for Front-End, Full Stack, Back-End or Junior Software Engineering roles.

How I build interfaces

  1. 1

    Plan the UI

    Break the design into pages and reusable components, and decide where state should live before writing code.

  2. 2

    Build it responsively

    Write clean HTML, CSS and React components that hold up on phones, tablets and desktops.

  3. 3

    Connect the data

    Integrate REST APIs and manage state with Redux Toolkit or Context API, with clear loading and error states.

  4. 4

    Debug and ship

    Test in the browser and Postman, tune performance, then deploy to Vercel.
